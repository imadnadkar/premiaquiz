== Description ==

Premia Quiz & Survey AI lets you create interactive quizzes and surveys with AI-powered question generation. Perfect for educators, course creators, and marketers.

**Features:**

* 12+ question types
* AI-powered question generation
* AI grading and feedback
* Lead capture forms
* Analytics dashboard
* WooCommerce integration
* Email marketing integrations
* REST API and webhooks

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/premiaquiz`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Quiz menu in WordPress admin to create your first quiz
